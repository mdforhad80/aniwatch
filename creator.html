Deployment Guide

GitHub Pages

1Create a new GitHub repository
2Upload all 6 HTML files to the repository
3Go to Settings > Pages
4Select "Deploy from a branch" and choose "main"
5Your site will be live at username.github.io/repo-name

Cloudflare Pages

1Sign up for Cloudflare and go to Pages
2Click "Create a project" and connect your GitHub repo
3Set build command to empty (static site)
4Set build output directory to "/" (root)
5Deploy and get your custom domain
